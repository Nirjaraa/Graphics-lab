# Graphics Lab Projects

This repository contains my graphics lab assignments and a mini-project implemented using **OpenGL**, **2D/3D transformations**, and **Three.js**.

---

## Lab 1 – Write Name
- Draw first name using **OpenGL polygons**  
- Fill polygons with a chosen color  

---

## Lab 2 – Line & Circle Drawing
- **DDA** and **Bresenham Line algorithms**  
- **Mid-point Circle**  
- Line graphs and pie charts using polygons  

---

## Lab 3 – 2D Transformations
- Midpoint **Ellipse Drawing**  
- **Translation, Rotation, Scaling, Reflection, Shearing**  
- Composite transformations on 2D shapes  

---

## Lab 4 – Clipping Algorithms
- **Cohen-Sutherland Line Clipping**  
- **Liang-Barsky Line Clipping**  
- **Sutherland-Hodgeman Polygon Clipping**  

---

## Lab 5 – 3D Transformations
- **Translation, Rotation, Scaling, Shearing** on 3D shapes  
- **Perspective Projection**  

---

## Mini-Project – DNA & RNA 3D Visualization
- Interactive 3D **DNA & RNA models** using **Three.js**  
- Rotatable, zoomable molecules with labeled bases (**A, T, C, G, U**)
